# Character and Word Counter

## About the Project
The Character and Word Counter is a simple web application built using HTML, CSS, and JavaScript. It allows users to count characters, words, and sentences in real time while typing in the text area.

## Features
- Live character counting.
- Live word counting.
- Live sentence counting.
- Automatically updates counts while typing.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the application in your browser.
2. Type or paste text into the text area.
3. View the character, word, and sentence counts instantly.
4. Edit or remove text to see the counts update automatically.

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.
4. Start typing to count characters, words, and sentences.
